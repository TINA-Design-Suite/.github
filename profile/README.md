## Four Beats

1. **Name the lab.** Give the TINA Design Suite session a short title before you edit the circuit schematic.
2. **Pin the live nets.** Keep current sources and probes on the TINA Design Suite board and leave unused parts aside.
3. **Check the plot.** Read the TINA Design Suite summary of the SPICE simulation before you treat a waveform as final.
4. **Close the loop.** Note which plots are ready so the next TINA Design Suite visit does not start by hunting the schematic.

## Field Note

TINA Design Suite is easier to trust when the schematic stays smaller than the bench it came from. A named session shows which lab is active, the pins show which nodes you will probe today, and the closing note tells the next person which SPICE simulation drives the waveform plots. That record is short on purpose: not a copy of every source, only the path back to the sheet that is still open.

The same loop fits a student amplifier, a client analog block, or a computer shared by two students. Open the last TINA Design Suite session, confirm one plot, and leave the voltages easier to read than you found them. Notebooks stay where they are. TINA Design Suite only holds the circuit schematic, the summary, and the handoff.

## One Real Pass

Pick a circuit that already has a name: a small RC filter, an op-amp stage, or a short rectifier. Open it in TINA Design Suite, keep only those nets on the board, and read one waveform you can point to. A pass is done when that plot is tied to the SPICE simulation and the unused parts are no longer in the way. TINA Design Suite does not need a full rebuild of the schematic before it is useful.

If the pass feels crowded, the sheet is too wide. Drop anything that belongs to a different lab and leave it out of this workspace. The next pass can have its own title. What matters is that this one stays readable from the first source to the last probe, with the summary still matching the waveform plots on the board.
